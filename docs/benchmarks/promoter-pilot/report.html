Human non-TATA promoter pilot from Genomic Benchmarks: 600 training, 200 validation, and 200 test sequences; each split balanced by class. Frozen Nucleotide Transformer v2 50M compared with conventional features. This filtered subset is not the full published benchmark.

Identical sequence splits, frozen features, and a shared logistic-regression protocol. C is selected by validation AUROC; the test set is evaluated after selection.

Interpretation limits

  • Exact/reverse-complement duplicates and shared exact 50-base windows are screened. This does not exclude approximate homology or genomic interval overlap.
  • Absent chromosome/locus groups, this is not a chromosome-held-out evaluation.
  • Foundation-model pretraining overlap with these genomes is not ruled out.
  • Bootstrap intervals condition on this fitted model and test class counts, assume independent sequences, and exclude training, split-selection, and pretraining uncertainty.
  • Brier score and log loss describe probabilities; no probability calibration is fitted.
